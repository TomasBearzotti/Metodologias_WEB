# 📚 Repositorio de la Materia

Bienvenido a mi repositorio de la materia. Aquí se encuentran organizados todos los proyectos, trabajos prácticos y ejercicios que fuimos realizando clase a clase a lo largo de la cursada.

## 📂 Estructura del Repositorio

El repositorio está dividido en distintas carpetas, cada una correspondiente a una actividad, práctica o proyecto específico. Cada carpeta es un proyecto independiente y cuenta con su propio archivo explicativo.

## 🚀 Navegación
Para ver el detalle de cada trabajo, simplemente ingresa a la carpeta correspondiente y lee su `README.md` local, donde se explica la consigna y la resolución de ese ejercicio puntual.
